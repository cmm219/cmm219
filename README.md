# cmm219

I build practical software for operational teams: internal dashboards, automation, data checks, messaging workflows, and workflow tools.

Most of my active work is private. The public repos here are selected examples, tools, and experiments that are safe to share.

What I work on:

- Internal operations platforms and admin dashboards
- Financially sensitive workflow tools where correctness matters
- Data integrity, reconciliation, audit, and release tooling
- Messaging, notification, and command-driven workflows
- Local desktop utilities and developer automation
- AI-assisted development with human review and production safeguards

Current public work:

- [Scrolly Polly Notely](https://github.com/cmm219/scrolly-polly-notely) - a small Windows-friendly floating notes app built with Python and Tkinter
- [mcstacks Codex Claude Skills](https://github.com/cmm219/mcstacks-codex-claude-skills) - Codex skills that use Claude Code for review, planning, and design feedback
- [ShiftPay](https://github.com/cmm219/ShiftPay) - a restaurant staff marketplace prototype for hospitality hiring

What I care about:

- Software that fits real operational workflows
- Clear release notes, focused tests, and verifiable behavior
- Data privacy and careful handling of user-impacting changes
- Local-first tools where local data matters
- Automation that reduces repeated manual work without hiding risk
- Practical engineering over novelty
