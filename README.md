## How I Build With Agents

I use agents as bounded collaborators, not unchecked committers.

- Codex owns repository state, edits, tests, commits, PRs, and final judgment.
- Claude Code is useful as a read-only reviewer, planner, or scoped design partner.
- High-risk work gets explicit approval gates, focused verification, and release records.
- Private project memory stays private; public repos contain sanitized patterns and examples.
