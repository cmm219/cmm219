# cmm219

I build practical software for teams whose work is mostly operational: dashboards, automation, data checks, and workflow tools.

Most of my active work is private. The themes below are drawn from private work, while the public repos here show selected tools, release practices, and experiments that are safe to share.

What I work on:

- Internal operations platforms and dashboards.
- Operational event, messaging, and notification workflows.
- Data integrity, reconciliation, and audit tooling.
- Content automation and media workflow tooling.
- Local desktop utilities and developer workflow automation.
- AI-assisted development with human review.

Current public work:

- [Scrolly Polly Notely](https://github.com/cmm219/ScrollyPollyNotely-public) - a small Windows-friendly floating notes app built with Python and Tkinter.
- [mcstacks Codex Claude Skills](https://github.com/cmm219/mcstacks-codex-claude-skills) - Codex skills that use Claude Code for review, planning, and design feedback.
- [ShiftPay](https://github.com/cmm219/ShiftPay) - a restaurant staff marketplace prototype for hospitality hiring.

What I care about:

- Software that fits real operational workflows.
- Local-first tools where local data and privacy matter.
- Automation that reduces repeated manual work.
- Clear docs, testable behavior, and honest release notes.
- Careful handling of production data and user-impacting changes.
